Meet **`/t/json-diff`** — a proper structural JSON comparison, not just a text diff.

## What it does

- **Structural mode** — walks both trees and reports `+ added`, `− removed`, and `~ changed` with the full JSON path (e.g. `$.author.email`).
- **Text mode** — flat patch output you can copy or download as `diff.patch`.
- **Ignore array order** — canonicalizes both sides so `[1,2,3]` and `[3,2,1]` compare equal.
- **Sort keys** — deterministic key order for stable review.
- **Show unchanged** — toggle to expand context around each change.
- **Swap** and **Format** in one click.

## Why

Text diffs on JSON are noisy — a reordered key or an extra comma drowns real changes. This tool diffs the *values*, not the whitespace, and reports paths you can act on.
