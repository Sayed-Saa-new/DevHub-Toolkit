DevHub Toolkit is live. 🎉

A **minimal, monochrome, keyboard-first** utility platform inspired by Vercel, Linear, Raycast, and GitHub — built for developers who don't want to jump between 12 tabs to format a JSON or decode a JWT.

## Highlights

- **58 tools** across converters, generators, design, editors, AI, and reference
- **AI helpers** powered by Gemini via server-side services — explain, optimize, generate SQL/regex, write commit messages
- **Command palette** with global search (<kbd>⌘K</kbd>)
- **Favorites** and **Recent tools**
- **Private by default** — most utilities run locally; AI helpers, URL fetching/schema validation, and feedback use server-side services
- **SEO-optimized** with per-tool metadata, JSON-LD, Open Graph, and sitemaps

Thanks for checking it out — more tools and polish shipping regularly.
