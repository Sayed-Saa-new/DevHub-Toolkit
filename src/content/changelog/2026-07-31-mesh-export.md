The **Mesh Gradient Generator** now ships with a dedicated **Export** panel.

- **Background toggle** — export with a solid stage color or a fully transparent PNG (real alpha channel)
- **Resolution scale** — 1×, 2×, 3× or 4× the stage size for crisp retina / print output
- **Custom width × height** override with live output dimensions readout
- Cleaner top bar — PNG/SVG buttons now live inside the Export panel next to their settings
